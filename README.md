Суть проєкту: 
У першій роботі я виконав початковий етап проєкту, а саме реалізував етапи Extract та Load концепції ELT. Було реалізовано генерацію транзакційних даних за допомогою Python та їх завантаження у сирий шар (`raw`) локального сховища даних у Docker. 

**Опис таблиць (Доставка квітів):**
* `clients` — інформація про клієнтів (ім'я, електронна пошта, дата реєстрації).
* `bouquets` — довідник букетів (назва, ціна, категорія).
* `florists` — список флористів (ім'я, досвід роботи).
* `deliveries` — таблиця доставок (зв'язок клієнта, букета та флориста, кількість, дата).
* `payments` — таблиця транзакцій/оплат (сума, зв'язок з доставкою та клієнтом).
* `reviews` — відгуки клієнтів про букети (оцінка, коментар).


Архітектура (Python -> Docker PostgreSQL): 
* **Python-скрипт:** за допомогою бібліотеки `Faker` генерує імітаційні транзакційні дані (`clients`, `bouquets`, `florists`, `deliveries`, `payments`, `reviews`), а за допомогою `Pandas` перетворює їх у `DataFrame`. Після цього пачки даних надсилаються до бази даних.

* **Docker PostgreSQL:** за допомогою бібліотеки `SQLAlchemy` дані завантажуються в БД PostgreSQL, розгорнуту в Docker-контейнері, де вони зберігаються у схемі `raw`.

Інструкція:
Потрібно завантажити сам проєкт, а також Docker. Після чого потрібно завантажити Python версії 3.9 або вище, якщо його немає на ПК, а також бібліотеки до нього (pandas, Faker, sqlalchemy, psycopg2-binary). Далі потрібно відкрити сам Docker і запустити його командою в консолі docker-compose up -d. Після чого запустити файл data_generator.py.
